# incident-response

## When to use
During an active production incident.

## Procedure
1. Assess severity (SEV1-SEV3).
2. First 15 minutes: acknowledge, assign owner, spin up comms channel.
3. Mitigate impact (rollback, scale up, hotfix).
4. Update customers/stakeholders.
5. Resolve and write a blameless post-mortem.

## Definition of Done
- Service restored.
- Post-mortem published and action items assigned.
